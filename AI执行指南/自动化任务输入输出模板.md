## 到货单据更新任务模板

### 输入表字段

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| 任务ID | 是 | 单条任务唯一标识 |
| 供应商 | 是 | 从供应商单据识别得到，用于图灵ERP搜索 |
| 采购单号 | 是 | 图灵ERP强校验字段 |
| 物料 | 是 | 与图灵ERP页面核对 |
| 颜色 | 是 | 与图灵ERP页面核对 |
| 到货数量 | 是 | 写入图灵ERP |
| 到货价格 | 是 | 写入图灵ERP |
| 状态 | 是 | 待处理 / 成功 / 失败 / 待人工确认 |
| 异常原因 | 否 | 失败或待确认时必填 |
| 操作时间 | 否 | 影刀执行完成后写回 |

### 执行流程

1. Agent识别供应商到货单据，提取供应商、采购单号、物料、颜色、数量、价格
2. Agent更新任务表，将可执行行状态写为“待处理”
3. 影刀读取任务表，只处理“待处理”行
4. 影刀进入图灵ERP待收货页面，按供应商和采购单号定位订单
5. 影刀核对采购单号、供应商、物料、颜色
6. 强校验通过后，填写到货数量和到货价格
7. 操作完成后，影刀或Agent写状态回任务表

### 输出状态规则

| 状态 | 写入条件 | 异常原因 |
|------|----------|----------|
| 成功 | 图灵ERP已提交，页面状态确认完成 | 可为空 |
| 失败 | 页面找不到订单、提交失败、系统异常 | 必填 |
| 待人工确认 | 供应商/采购单号/物料/颜色任一字段无法确认 | 必填 |

### 汇报格式

```text
任务：到货单据更新
任务表：文件名/路径
成功：X条
失败：X条
待人工确认：X条
已写回状态：是/否
异常明细：任务ID + 采购单号 + 原因
```
