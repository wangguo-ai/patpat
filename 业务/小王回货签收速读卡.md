# 小王回货签收速读卡

用途：每次用户说“小王，回货签收，供应商单据我更新好了”，先读本页，再看当天文件。不要先翻长复盘。

## 固定路径

- 供应商单据：`D:\报销工作台\01_供应商单据`
- 采购导出：优先用户给的 `D:\Gemini Chrome下载\版料采购单YYYY年MM月DD日.xlsx`
- WorkBuddy：`D:\报销工作台\04_WorkBuddy任务\WorkBuddy采购入库任务表.xlsx`
- 飞书：`lark-cli.cmd --profile cli_aabb9de267395cde ... --chat-id oc_4070d243f4bf5f6c5c2a4fd5f2d11c32`

## 开工顺序

1. 先列最新供应商单据，人工看图；OCR 识别不出时不要拖节奏。
2. 读采购导出，按供应商、物料编号、颜色、色号、数量匹配 MCG。
3. 生成待写清单：`采购单号 / 数量 / 实际单价 / 金额 / 来源单据 / 备注`。
4. 写 WorkBuddy 前先备份；当天需要影刀操作的写到当前操作页（`影刀操作明细`），已执行完的归档到 `已经执行完的任务`，不要混放。
5. 写后回读：缺失、重复、`?` 乱码、供应商汇总、整批总额。
6. 飞书同步必须发，且按“供应商单据 -> 对应采购单号”格式发。

## WorkBuddy 分页

- `影刀操作明细`：只放当天/当前批次需要影刀继续操作的待执行任务。
- `已经执行完的任务`：放历史已执行任务；不要把已执行任务留在当前操作页干扰影刀。
- 追加行不要用 `ws.max_row + 1`，按关键列找真实空行；写前备份，写后按两个分页分别回读。

## 看图防错

- 每张图都先读抬头、地址、电话、物料名；不能继承上一张图片的供应商。
- 手写单尤其要看抬头。2026-07-13 曾把“广新米白 2 米”误判成鑫悦。
- 同物料同色号多 MCG 时，先查 WorkBuddy 已写入哪些，再把新增数量拆给未写入 MCG。
- 用户说旧单、多余、不用管：只在飞书说明，不写 WorkBuddy。

## 高风险规则

- 怡丰：优先看红字/底部总额；常有每米优惠 10 元，不能只抄行面价或参考价。
- 宝年丰/恒业/华讯昌达等：供应商按公斤/KG，采购按米，必须用供应商金额倒核米价。
- 鑫悦：同色号可能拆多个 MCG；本白等按 KG 开单时按采购米数换算。
- 广新：75D双面佳积布米白/148# 可能有多张 1 米 MCG，要按已写/未写拆。

## 飞书格式

逐条短消息发送，不发长多行文本：

`1. 供应商 | 单据号 / 物料颜色 | 对应：MCG..., MCG...`

末尾：

`合计：X 张采购单，已写入 WorkBuddy，金额合计 Y 元。`

多余单据：

`说明：供应商/单据号/物料 是多余单据，本次不录入。`
