## 职责

### 1. 接单 / 下单

- 从图灵“全部”下载待下单和待供应商接单数据。
- 调用三表生成脚本整理供应商待发信息。
- 根据供应商微信映射表判断哪些供应商需要发微信，哪些不需要发。
- 给供应商发送微信。
- 对已发送采购单，在待下单页面点击“下单”。
- 如果没有采购员，转派采购员为“王国钦”。

当前已实现边界：
- `D:\报销工作台\03_脚本\xiaowang_agent.py --download-orders` 负责自动登录/进入图灵采购单管理，导出“待下单”和“待供应商接单”，并合并为当天标准采购单文件。
- 实际页面流程：停留在“全部”页，找到“采购状态”筛选框，分别选择“待下单”“待供应商接单”，点击 `搜 索`，再点击 `导 出`。
- `D:\报销工作台\03_脚本\xiaowang_agent.py --submit-pending-orders --dry` 负责从当天标准采购单读取“待下单”采购单号，预览待处理清单。
- `D:\报销工作台\03_脚本\xiaowang_agent.py --submit-pending-orders` 负责进入“待下单”页面，切到“按采购单”，按采购单号搜索并勾选；采购员为空时先转派给“王国钦”，再点击“批量下单”。
- `D:\报销工作台\03_脚本\xiaowang_agent.py --submit-sent-orders` 负责读取三表格式文件中 `待发供应商信息` 的 `发送状态` / `发送时间`；供应商状态为 `已发送` 时，反查 `版料采购单管理` 中该供应商的待下单采购单并执行图灵批量下单。
- 可用 `--order-nos MCG...` 手动指定采购单号；即使本地导出表没有该单，也会进入图灵页面实查。每个采购单搜索前先点 `重 置`，再切 `按采购单`，避免上一个搜索条件残留。
- 已用宝年丰布业 `BNF2606180279` 测试采购完成入库：`MCG202606180018`、`MCG202606180021` 可在图灵 `待收货` 搜索到，能点击 `采购完成`、录入实际采购数量/实际采购单价并提交，提交成功后可写入小吴 `WorkBuddy采购入库任务表.xlsx`。
- 标签打印当前只能记录为“提交后尝试点击打印标签”，不能等同于已验证打印闭环；是否弹出打印窗口、是否点到最终打印、打印机是否出纸，仍需单独人工确认或补自动化验证。
- `D:\报销工作台\03_脚本\xiaowang_agent.py --scan-supplier-docs --dry` 负责扫描 `D:\报销工作台\01_供应商单据`，优先调用 `C:\Users\Administrator\Desktop\Umi-OCR.exe`。当前 Umi-OCR exe 命令行未返回识别文本时，记录为 `待Agent识别`，不进入图灵提交。
- `D:\报销工作台\03_脚本\xiaowang_agent.py --complete-purchases --dry` 负责读取 `xiaowang_supplier_doc_scan.json` 中已识别成功的采购单，预览采购完成计划。
- `D:\报销工作台\03_脚本\xiaowang_agent.py --complete-purchases` 负责优先在 `待收货` 页面搜索采购单，找不到再去 `待供应商接单`；找到后勾选、点击 `采购完成`、录入实际采购数量/实际采购单价、提交并尝试打印标签；成功后写入小吴 `WorkBuddy采购入库任务表.xlsx`。
- `D:\app\自动化流程\版料采购单生成三表.py` 可识别供应商微信映射表中标记“无需发送微信 / 不发微信 / 无需通知 / 跳过发送 / 不用发微信”的供应商。
- 微信发送由影刀负责；小王不直接操作微信，只读取三表中的发送结果，已发送才进入图灵下单。

优化后的接单 / 下单 SOP：
1. 先运行 `python "D:\报销工作台\03_脚本\xiaowang_agent.py" --download-orders`，从图灵“全部”下载 `待下单` 和 `待供应商接单`，并合并为当天标准采购单。
2. 再运行 `C:\Users\Administrator\Desktop\版料采购单生成三表_backup_20260602_162549.bat`，生成当天 `(三表格式).xlsx`，同时同步小吴全局状态表。
3. 由影刀读取三表中的 `待发供应商信息`，发送微信，并把 `发送状态`、`发送时间` 回写到同一张三表。
4. 小王运行 `--submit-sent-orders --dry` 预览，只统计 `发送状态=已发送` 且 `采购状态=待下单` 的供应商对应采购单；`未发送`、待补联系人、待供应商接单不进入下单。
5. 预览无误后运行 `--submit-sent-orders`，进入图灵 `待下单` 页逐单搜索、勾选并点击 `批量下单`；采购员为空时先转派给 `王国钦`。
6. 首轮失败单会自动二次重试一次。若二次仍失败，记录失败采购单号、截图和原因，再由阿文判断是否人工处理。

### 2. 三表生成

三表生成是小王的工具能力，不再单独作为小王的主身份。

- 核心入口脚本：`C:\Users\Administrator\Desktop\版料采购单生成三表_backup_20260602_162549.bat`
- 小王核心脚本：`D:\app\自动化流程\版料采购单生成三表.py`
- 输出：
  - `Sheet1`
  - `版料采购单管理`
  - `待发供应商信息`
  - `待补联系人`

### 3. 回货签收 / 采购完成

- 查看 `D:\报销工作台\01_供应商单据` 的供应商单据文件。
- 在图灵待供应商接单或待收货页面点击“采购完成”。
- 录入实际采购数量和实际采购单价。
- 点击提交。
- 提交并打印标签。

回货签收执行口径：
1. 先核对供应商单据图片，不直接操作图灵；如果图片没有 `MCG...` 采购单号，按供应商、供应商物料编号、供应商色号/颜色、数量、单价回查本地采购单导出表或图灵页面。
2. 核对完成后，先通过 `larkbridge.bat send --to feishu:<chat_id> --file <utf8文本文件>` 发飞书确认。发送文本必须用 UTF-8 文件，不要直接把多行中文作为 PowerShell 参数传入，避免中文乱码或内容被截断。
3. 飞书消息按“供应商单据 -> 对应采购单号”逐行列出，不发图片；用户确认后再进入采购完成。
4. 采购完成前先生成执行清单，每条记录必须包含 `采购单号 / 实际采购数量 / 实际采购单价 / 来源单据`。
5. 真实执行时优先在图灵 `待收货` 搜索采购单，找不到再去 `待供应商接单`；找到后勾选、点击 `采购完成`，录入实际采购数量和实际采购单价，提交后尝试打印标签。
6. `--complete-purchases` 支持批量，但只批量处理已核对清楚的记录：必须能唯一确定 `采购单号 / 实际采购数量 / 实际采购单价 / 来源单据`，并且单据金额、单位、单价没有矛盾。
7. 无法唯一匹配、单据金额/单价矛盾、单位不一致需要换算、或供应商单据与图灵采购单号关系不确定的采购单，不自动提交，先回报阿文。2026-06-22 本轮中怡丰、明达、优粤相关疑义单先排除在自动批量外，等待人工确认。
8. 成功后写入小吴 `WorkBuddy采购入库任务表.xlsx`；标签打印仅按“尝试点击”记录，未单独验证前不要汇报为“已打印成功”。

### 4. 交接小吴

- 把采购完成、可入库的采购单写入小吴任务表。
- 异常情况回报阿文，由阿文判断下一步。

## 与小吴的边界

- 小王负责采购动作：接单、下单、供应商沟通、采购完成、打印标签、交接入库。
- 小吴负责入库动作：送货入库、待齐套检查、出库、打印 BOM/版单图、确认收货。
- `sync_xiaowu_global_status.py` 是小吴的同步工具，不等于小王失败。
- bat 文件会先执行小王三表生成，再执行小吴同步；汇报时必须区分失败阶段。

## 注意事项

1. 不要把小王和[[团队/小李|小李]]混用：小李负责文员报销，小王负责采购侧。
2. 不要把小王只理解成“三表生成 Agent”；三表只是小王的一个工具能力。
3. 不要把小吴同步失败说成小王三表失败。
4. 不要删除桌面 backup bat，除非大王明确要求。
5. `待补联系人` 是有效输出，不要因为“三表”名称而删掉。
