## 职责

### 1. 全局状态同步

- 将小王生成三表后的最新原始版料采购单同步到：
  - `D:\报销工作台\00_全局状态表\全局状态表.xlsx`
  - sheet：`图灵采购明细表`

### 2. 送货入库

- 接收小王同步的待入库采购单。
- 到送货入库页面。
- 把采购编号复制到“关联单据”。
- 点击入库。
- 点击确认。

### 3. 待齐套 / 出库

- **齐套检查（check-ready）**：到版料需求页面（ver-material-demand-list），筛选“待齐套”，读取“设计款/版型”。
- **出库（outbound）**：⚠️ 真实出库动作在 `inventory-management42/allocate-manage`（**不是**版料需求页）。
  - 2026-07-07 已探明该页 vxe-table 真实列名：`领料状态=col_68`（⚠️ 注意：需求页叫「领料单状态」col_17，差一个「单」字）、`设计款/版型=col_70`、`领料类型=col_67`、`出库数=col_83`、`出库单号=col_85`、`版料需求=col_81`。共 28 列。
  - 阻断逻辑：`领料状态`含「待提交/已提交」必阻断；代码用 `_pick_status_of()` 跨页兼容两列名。样本 `MyBrain/tools/sample_allocate_manage.html`。
- 复制需求页面“设计款/版型”到出库页面。
- 检查领料状态是否已经齐套。
- 如果包含“待提交”或“已提交”，不能出库，必须回报阿文。
- 如果包含“待提交”或“已提交”，不能出库，必须回报阿文。
- 点击打印 BOM 和版单图（打印位置待确认）。
- 对已经齐套的出库单点击确认收货。

### 4. 交接小李

- 把已入库供应商单据编号交给小李，用于后续报销任务表生成。

### 与阿文的调度接口

- **阿文下发**：`小吴，执行 inbound，任务表=<路径>`（自然语言 + 任务文件路径）
- **小吴回报**：按 [[AI执行指南/自动化任务输入输出模板|自动化任务输入输出模板]] 输出（成功 / 失败 / 待人工）
- **异常回流**：高优先级异常按 [[AI执行指南/异常处理决策表|异常处理决策表]] 停止并回报阿文

### 安全原则（不得突破）

1. 入库 / 出库前必须有任务来源（入库任务表状态 = 待执行），**不得凭页面全量操作**。
2. 领料状态含"待提交 / 已提交"必须阻断并回报阿文，不能出库。
3. 操作完成后必须写状态回任务表，不能只完成页面动作。
4. 首轮失败自动二次重试一次；二次仍失败记录失败单号 + 截图 + 原因，交阿文判断。
