## 职责

### 1. 全局状态同步

- 将小王生成三表后的最新原始版料采购单同步到：
  - `D:\报销工作台\00_全局状态表\全局状态表.xlsx`
  - sheet：`图灵采购明细表`

### 2. 送货入库

- 接收小王同步的待入库采购单。
- 到送货入库页面。
- 把采购编号复制到“关联单据”。
- 点击入库。
- 点击确认。

### 3. 待齐套 / 出库

- 到版料需求页面。
- 在需求状态筛选“待齐套”。
- 复制需求页面“设计款/版型”到出库页面。
- 检查领料状态是否已经齐套。
- 如果包含“待提交”或“已提交”，不能出库，必须回报阿文。
- 点击打印 BOM 和版单图。
- 对已经齐套的出库单点击确认收货。

### 4. 交接小李

- 把已入库供应商单据编号交给小李，用于后续报销任务表生成。

> 状态：CLI 主入口已于 2026-07-06 落地（7 子命令）；2026-07-07 补全 `check-ready` / `outbound` / `print-bom` 三子命令——`check-ready` 已接通全局状态表（读 888 行、筛待齐套候选）+ 图灵版料需求页（vxe-table，齐套情况位列 td[10]、领料状态列 td[9]）；`outbound` 出库硬规则（领料状态含「待提交/已提交」必须阻断）已落成代码并通过验证（demo 阻断/放行均正确）；`print-bom` 已结构化。三者图灵页面交互层（版料需求页 `ver-material-demand-list` 等真实 URL 与 vxe-table 选择器）已于 2026-07-07 通过大王本机 Chrome CDP 探查确认并补全。`sync-global` 复用 `sync_xiaowu_global_status.py`；`inbound` 复用 `yingdao-rpa/purchase_auto_inbound.py`；`handoff` 可生成交接清单。**所有子命令默认 dry-run，加 `--exec` 才真实执行**（exec 会连 CDP:9222 操作图灵）。详见 [[技术/多Agent协作|多Agent协作 · 开发实现]]。

### CLI 子命令规划（对应原 8 条缺口）

| 子命令 | 对应缺口 | 设计要点 | 复用 / 图灵页面 |

| `outbound` | 5、7 | 检查领料状态，含"待提交/已提交"必须阻断；已齐套 → 确认收货 | 新写，含阻断逻辑 |

### 与阿文的调度接口

- **阿文下发**：`小吴，执行 inbound，任务表=<路径>`（自然语言 + 任务文件路径）
- **小吴回报**：按 [[AI执行指南/自动化任务输入输出模板|自动化任务输入输出模板]] 输出（成功 / 失败 / 待人工）
- **异常回流**：高优先级异常按 [[AI执行指南/异常处理决策表|异常处理决策表]] 停止并回报阿文

### 安全原则（不得突破）

1. 入库 / 出库前必须有任务来源（入库任务表状态 = 待执行），**不得凭页面全量操作**。
2. 领料状态含"待提交 / 已提交"必须阻断并回报阿文，不能出库。
3. 操作完成后必须写状态回任务表，不能只完成页面动作。
4. 首轮失败自动二次重试一次；二次仍失败记录失败单号 + 截图 + 原因，交阿文判断。

- 入库和出库前都要有任务来源和失败回写，不能凭页面全量操作。
