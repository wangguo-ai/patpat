## 职责

### 1. 全局状态同步

- 将小王生成三表后的最新原始版料采购单同步到：
  - `D:\报销工作台\00_全局状态表\全局状态表.xlsx`
  - sheet：`图灵采购明细表`

### 2. 送货入库

- 接收小王同步的待入库采购单（MCG 采购需求号）。
- 打开送货入库页（`inWarehouse-manage`）。
- ⚠️ **切「版料」tab**（BC端采购单在版料tab；大王 2026-07-08 确认"不用切大货，就是版料的"）。
- 点「展开」按钮（`.expand` 类）显示筛选区。
- 在筛选区「关联单据」输入框（`.ant-form-item` 的 label 含"关联单据"）填 MCG 单号。
- 点「搜索」→ 结果行即目标单。
- 点该行「入库」按钮 → 弹窗确认（入库数量系统已带出，必填）。
- 弹窗点「确认」→ 验证状态变「已完成」。
- ⚠️ **关键坑①**：顶部全局搜索框(placeholder=请输入)只绑「入库申请单」(MRK)列，填 MCG 返回空表 —— **必须用「关联单据」筛选框**！
- ⚠️ **关键坑②（根因）**：「关联单据」是 antd 受控表单，用 JS `setter` 改 `input.value` 不会同步进 React Form state，搜索参数没带上（抓包显示值误写进 `document` 字段 → 0 行）。**必须用 Playwright 原生 `fill` 触发 React onChange**。但**不能用** `.ant-form-item:has(.ant-form-item-label:has-text("关联单据")) input` 定位器（该页面会异常匹配 20+ 个 hidden input）；正确做法：先用 JS 评估找到 label 含"关联单据"的 `.ant-form-item` 内的 `input`、打 `data-rel-doc="1"` 标记，再 `page.fill('input[data-rel-doc="1"]', 单号)` 并校验 `input_value()`。
- ✅ 流程已实机验证（2026-07-08）：`MCG202607070008` 自动入库成功；`MCG2026070700039` 大王手动完成；`MCG202607070041` **自动入库成功（状态=已完成，首次用修复后的 xiaowu_agent.py 回测通过）**，确认 antd 原生 fill + data-rel-doc 定位 + JS 去空格点搜索整套修复有效。

### 3. 待齐套 / 出库

- **齐套检查（check-ready）**：到版料需求页面（ver-material-demand-list），筛选“待齐套”，读取“设计款/版型”。
- **出库（outbound）**：⚠️ 真实出库动作在 `inventory-management42/allocate-manage`（**不是**版料需求页）。
  - 2026-07-07 已探明该页 vxe-table 真实列名：`领料状态=col_68`（⚠️ 注意：需求页叫「领料单状态」col_17，差一个「单」字）、`设计款/版型=col_70`、`领料类型=col_67`、`出库数=col_83`、`出库单号=col_85`、`版料需求=col_81`。共 28 列。
  - 阻断逻辑：`领料状态`含「待提交/已提交」必阻断；代码用 `_pick_status_of()` 跨页兼容两列名。样本 `MyBrain/tools/sample_allocate_manage.html`。
- 复制需求页面“设计款/版型”到出库页面。
- 检查领料状态是否已经齐套。
- 如果包含“待提交”或“已提交”，不能出库，必须回报阿文。
- 如果包含“待提交”或“已提交”，不能出库，必须回报阿文。
- 点击打印 BOM 和版单图（打印位置待确认）。
- 对已经齐套的出库单点击确认收货。

### 4. 交接小李

- 把已入库供应商单据编号交给小李，用于后续报销任务表生成。

### 与阿文的调度接口

- **阿文下发**：`小吴，执行 inbound，任务表=<路径>`（自然语言 + 任务文件路径）
- **小吴回报**：按 [[AI执行指南/自动化任务输入输出模板|自动化任务输入输出模板]] 输出（成功 / 失败 / 待人工）
- **异常回流**：高优先级异常按 [[AI执行指南/异常处理决策表|异常处理决策表]] 停止并回报阿文

### 安全原则（不得突破）

1. 入库 / 出库前必须有任务来源（入库任务表状态 = 待执行），**不得凭页面全量操作**。
2. 领料状态含"待提交 / 已提交"必须阻断并回报阿文，不能出库。
3. 操作完成后必须写状态回任务表，不能只完成页面动作。
4. 首轮失败自动二次重试一次；二次仍失败记录失败单号 + 截图 + 原因，交阿文判断。
