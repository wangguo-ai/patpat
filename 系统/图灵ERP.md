| **全称** | Turing ERP — 面辅料MRP系统 |
| **核心模块** | 版料采购管理（Plate Material Management） |

## 采购全流程

```mermaid
flowchart LR
    A[取单] --> B[录入]
    B --> C[入库]
    C --> D[确认]
```

### 1. 取单
- 从系统下载待接单文件
- 进入：供应链 → 面辅料MRP → 版料管理 → 采购管理列表

### 2. 录入
- 在待收货页面操作
- 搜索供应商名称定位订单
- 核对采购单号、物料、颜色

### 3. 入库
- 填写到货数量
- 填写到货价格
- 勾选订单前复选框 → 点击"采购完成"

### 4. 确认
- 最终确认入库
- 打印标签

## 到货单据更新业务

> 供应商到货单据识别后，通过任务表驱动影刀操作图灵ERP，并将执行状态写回表格。

### 业务链路

```mermaid
flowchart LR
    A[识别供应商单据] --> B[更新任务表]
    B --> C[影刀读取任务表]
    C --> D[操作图灵ERP]
    D --> E[写状态回表格]
    E --> F[人工复核异常项]
```

### 核心职责分工

| 环节 | 执行者 | 输入 | 输出 |
|------|--------|------|------|
| 识别供应商单据 | Agent / OCR | 供应商单据图片或文件 | 供应商、采购单号、物料、颜色、数量、价格 |
| 更新任务表 | Agent | 单据识别结果 | 待影刀执行的任务表 |
| 操作图灵ERP | 影刀RPA | 任务表中的待处理行 | 图灵ERP到货数量、价格、入库状态 |
| 写状态回表格 | 影刀RPA / Agent | 图灵ERP操作结果 | 成功、失败、待人工确认及原因 |

### 任务表建议字段

| 字段 | 用途 |
|------|------|
| 任务ID | 单条任务唯一标识 |
| 供应商 | 图灵ERP页面搜索和人工校验 |
| 采购单号 | 强校验字段，防止更新错单 |
| 物料 | 到货单据与图灵ERP页面校验 |
| 颜色 | 到货单据与图灵ERP页面校验 |
| 到货数量 | 写入图灵ERP |
| 到货价格 | 写入图灵ERP |
| 状态 | 待处理 / 成功 / 失败 / 待人工确认 |
| 异常原因 | 失败或待确认时必须填写 |
| 操作时间 | 写回状态时记录 |

### 执行原则

1. 任务表是影刀操作图灵ERP的中间控制表
2. 影刀只处理状态为“待处理”的行
3. 更新图灵ERP前必须核对采购单号、供应商、物料、颜色
4. 任一强校验字段不一致，不得提交“采购完成”
5. 操作完成后必须写状态回表格，不能只在图灵ERP页面结束

## 操作注意事项

- 搜索供应商后，逐个核对采购单号
- 点击"采购完成"前**必须勾选**订单前的复选框
- 数量、价格需与采购订单一致
- 部分供应商（如广信面料店 ID:30）需注意区分（广信 vs 广盛）
