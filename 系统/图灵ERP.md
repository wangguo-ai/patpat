## 采购全流程

```mermaid
flowchart LR
    A[取单] --> B[录入]
    B --> C[入库]
    C --> D[确认]
```

### 1. 取单
- 从系统下载待接单文件
- 进入：供应链 → 面辅料MRP → 版料管理 → 采购管理列表

### 2. 录入
- 在待收货页面操作
- 搜索供应商名称定位订单
- 核对采购单号、物料、颜色

### 3. 入库
- 填写到货数量
- 填写到货价格
- 勾选订单前复选框 → 点击"采购完成"

### 4. 确认
- 最终确认入库
- 打印标签

## 操作注意事项

- 搜索供应商后，逐个核对采购单号
- 点击"采购完成"前**必须勾选**订单前的复选框
- 数量、价格需与采购订单一致
- 部分供应商（如广信面料店 ID:30）需注意区分（广信 vs 广盛）
